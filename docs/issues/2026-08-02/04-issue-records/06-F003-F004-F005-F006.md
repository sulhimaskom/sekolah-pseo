## F003 — Global concurrency groups serialize unrelated workflows
**Labels**: `ci`, `P2` | **Files**: `.github/workflows/on-push.yml:11`, `on-pull.yml`

- `concurrency: group: global` serializes ALL workflow runs repo-wide, creating queue
  backlogs (turnstyle "Wait in Queue" steps) and slowing change velocity.
- **Evidence**: on-push.yml line 11 `group: global`; on-pull.yml `group: oc-agent`.
- **Suggested fix**: per-workflow/per-branch concurrency groups.

---

## F004 — Excessive CI secret exposure/aliasing
**Labels**: `security`, `P1` | **Files**: all `.github/workflows/*.yml`

- 57 `secrets.*` references, 10 distinct secret names; `API_KEY` aliased to
  `GEMINI_API_KEY` (also F013 CRITICAL); `VITE_SUPABASE_ANON_KEY` mis-mapped to
  `VITE_SUPABASE_KEY` in on-push.yml.
- **Suggested fix**: remove unused secret env vars; delete alias entries; scope
  secrets per-job to the minimal set.

## F005 — Prettier violations in docs (18 files)
**Labels**: `docs`, `P3` | **Files**: `docs/issues/**`, `docs/audit/**`

- `npm run format:check` fails: 18 files (up from 16) — all under `docs/issues/` and
  `docs/audit/`. `npm run format` fixes them. Docs workflow should run prettier --write.
- **Suggested fix**: add `docs/**` to lint-staged; run `npx prettier --write docs`.

## F006 — SITE_URL default placeholder
**Labels**: `chore`, `P2` | **Files**: `scripts/config.js:50-54`, `.env.example`

- Build warns: `SITE_URL is set to default placeholder "https://example.com"`.
  Production deployments silently emit example.com URLs if env missing.
- **Suggested fix**: fail build in production mode when SITE_URL is unset; document in
  docs/deployment.md.
