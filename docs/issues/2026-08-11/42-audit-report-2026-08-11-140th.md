## Source audit (contract §6 delegation) — surfaced F115

Two parallel `explore` subagents (src/presenters+services; scripts/) audited code
quality beyond the standard matrix. Highest-severity NEW finding, verified
empirically in-session:

- **F115 (bug, P1): `escapeCsvField` corrupts negative numeric coordinates.**
  `scripts/utils.js` prefixes every value starting with `-` with a single quote
  (formula-injection guard). Numeric literals such as latitude `-6.2088` become
  `'-6.2088`; consumers parsing with `parseFloat()` get `NaN` — silent data
  corruption on the `etl.js → writeCsv → data/schools.csv` export path. Indonesia
  is predominantly south of the equator (sample rows: SMA Negeri 1 Jakarta
  `-6.2088`, SD Negeri 2 Bandung `-6.9175`). Verified: `escapeCsvField('-6.2088')`
  → `'-6.2088`, `parseFloat` → `NaN`; positive `106.8456` passes clean; live
  `writeCsv` round-trip produced `lat='-6.2088`. **Fixed in this run** (numeric
  literal exemption `/^-?\d+(\.\d+)?([eE][+-]?\d+)?$/`; formula-like strings
  `-1-1`, `-2*3`, `=SUM(...)` still prefixed). Post-fix suite:
  **1093 tests / 1089 pass / 0 fail / 4 skipped**; coverage 95.2% stmt / 92.93%
  branch; build PASS; lint 0/0; prettier clean on changed files.

Other explore findings (medium/low, noted for the ledger, not minted as scored
findings this run): `writeCsv` non-atomic write; `fastWriteFile` unlink-then-write
window; `--radius-full` CSS token used but not emitted (visual); client-side
`downloadCsv` unguarded for formula injection; empty catches in PageBuilder /
BuildOrchestrator; `CURRENT_YEAR` module-capture staleness in footer.
