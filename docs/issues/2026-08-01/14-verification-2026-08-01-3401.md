### F015 Status This Run (EXPLOITABLE — live PoC)

PoC executed against the actual module (no file written, in-memory only):

```
PASSES: "https://github.com/foo/bar.git"      -> unchanged
PASSES: "https://github.com/foo/bar;id.git"   -> "https://github.com/foo/bar;id.git"   ← survives
PASSES: "https://github.com/foo/bar$(id).git" -> "https://github.com/foo/bar$(id).git" ← survives
REJECTED: "https://github.com/foo/bar.git;ls" -> (fails .git suffix check only)
```

Attack chain: `--source` CLI arg (`fetch-data.js:329-330`) → `fetchFromGitHub` →
`validateRepoUrl` (line 55, reconstructs `${protocol}//${hostname}${pathname}` with
**zero shell-metacharacter stripping**, only `.git` suffix check) → `execGitCommand`
(line 177: `git clone --depth 1 ${safeRepoUrl}`) → `execSync` (`/bin/sh -c`). A URL
ending in `.git` carrying `$(…)` or `;` executes arbitrary OS commands. If untrusted
URL input ever reaches `fetchFromGitHub`, this is **RCE**. Fix is small and safe:
`execFileSync('git', ['clone', '--depth', '1', safeRepoUrl, dir], opts)` + stricter
regex whitelist `[a-zA-Z0-9._/-]`.
